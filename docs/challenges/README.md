# Weekly challenges

Each Monday, an automated routine writes `week-NN.md` here, including the full spec and
acceptance tests, on a branch named `claude/week-NN-<slug>`, and opens a draft pull
request. You implement the feature on that branch. On Friday, a review routine checks
CI, reviews the diff against the spec and comments on the PR. Merge when it's done;
the merge checks the week off in ROADMAP.md.
